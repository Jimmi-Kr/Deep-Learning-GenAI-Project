# Deep Learning & Generative AI Project
### Diploma Level, BS in Data Science and Applications

## What this project is about

This project gives you hands-on experience in end-to-end machine learning workflows — from dataset handling and model training to evaluation, deployment, and reporting.

You will:

- Work with **GitHub** for code and project organization
- Use **Kaggle** for competition-style inference and benchmarking
- Track experiments and metrics with **Weights & Biases (W&B)**
- *(Optional bonus)* Deploy your final model on **Hugging Face Spaces**

The project runs for approximately **8 weeks**, starting **{{ site.data.term.project_release_date }}**.

🔗 [Kaggle Competition Link]({{ site.data.term.kaggle_competition_link }})

This is an **individual project**. Before you start, create accounts on: Kaggle, GitHub, Weights & Biases, and Hugging Face.
